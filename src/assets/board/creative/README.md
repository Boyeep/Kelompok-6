# Aset kreatif bulletin board

Koleksi 35 SVG dari tim kreatif, dikelompokkan berdasarkan bentuk dan diberi nama yang mudah dicari. Dua bagian siluet kucing (`Polygon 21.svg` dan `Polygon 22.svg`) dihapus; isi SVG lainnya tetap sama dengan berkas ekspornya di PR #45.

| Folder | Isi | Jumlah |
| --- | --- | ---: |
| `papers/` | Notepad untuk to-do list | 4 |
| `tapes/` | Selotip dekoratif | 3 |
| `stickers/` | Gambar dekoratif, termasuk tiga kertas tempel | 15 |
| `stationery/` | Pensil dan penjepit kertas | 3 |
| `memes/` | Stiker reaksi; SVG membungkus gambar tertanam | 10 |

Empat notepad di `papers/` tersedia pada pilihan **Ganti kertas** untuk tiap to-do list. Tiga bentuk kertas lainnya menjadi stiker di `stickers/`. Semua aset dari `tapes/`, `stickers/`, `stationery/`, dan `memes/` tersedia dalam satu pilihan **Aset papan**. Daftar dan ukuran tampilannya ada di [katalog aset](../../../js/asset-catalog.js); [service worker](../../../service-worker.js) memuat katalog yang sama untuk cache offline.
